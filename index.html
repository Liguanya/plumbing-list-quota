💧 给排水专业智能组价系统

天津2025清单计价规范 · Excel上传自动识别管道材质/管径/阀门并套清单定额 · 铸铁管可选室内外与接口形式 · 主材价联动天津信息价 · 全部本地计算

📋 使用说明与价格参考

  • 上传给排水工程量清单 Excel（.xlsx/.xls），A列=序号、B列=项目名称（材质/管径/接口形式）、C列=数量、D列=单位（可选，m/m²/m³），首行可为表头；阀门写 蝶阀-300 时，-300 即 DN300（也可写 DN300），按国标 DN 系列识别，压力/电压等后缀不按管径处理；系统按项目名称自动识别材质、公称直径与连接方式并套用清单与定额，结果支持「广联达 / 建经科技」两种格式导出。
  • 图纸说明优先：左侧可先上传图纸说明（PDF / DWG / DXF / TXT），平台按段落上下文识别管材、连接方式、安装部位、系统、管径分档、试验与措施要求——CAD 提取的换行不会割裂「管材…接口为…连接」的对应关系，同一句里多条管径分档（≥DN65卡箍／<DN65螺纹、DN100及以上／DN80及以下）会分别成条，管材与连接方式分处两句时按就近上下文配对；再上传右侧工程量清单，管道连接方式等按说明自动套用，无需逐条手选；说明与清单不一致时会给出对比分析（漏系统、漏材质、漏保温套管、管径越界等）。说明解析全部在本地完成，文件不上传服务器。
  • 塑料管：名称含 PVDF、聚乙烯（PE）、聚丙烯（PP-R）、聚丁烯（PB）、聚氯乙烯（PVC-U）等关键词的管道按塑料管组价，「安装部位/接口形式」列为三级联动——一级选室内/室外；室外二级直接选连接方式（热熔 / 电熔 / 粘接，公称外径 32~315mm）；室内二级选雨水管 / 排水管 / 给水管，三级选连接方式（排水：粘接 / 热熔 / 螺母密封圈；雨水：粘接；给水：热熔 / 电熔 / 粘接），切换后定额、主材价与项目特征实时重算。名称中也可直接写明，如 室内聚乙烯PE给水管 De110 热熔连接。
  • 价格参考：天津市工程造价信息（2026年1—10期）及市场价——页面顶部「信息价期号」可选择期次（默认最新一期），切换后主材价按该期信息价重新计算；信息价有的按信息价计入（页面不标品牌），信息价缺项的按国产中高档市场价并给出参考品牌。
