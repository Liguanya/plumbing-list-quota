💧 给排水专业智能组价系统

天津2025清单计价规范 · Excel上传自动识别管道材质与管径并套清单定额 · 铸铁管可选室内外与接口形式 · 主材价联动天津信息价 · 全部本地计算

📋 使用说明

  • 录入给排水专业工程量清单 Excel（.xlsx/.xls），A列=序号、B列=项目名称（材质/管径/接口形式）、C列=长度（m），首行可为表头；上传后系统按项目名称自动识别材质与公称直径并套用清单与定额，结果支持「广联达 / 建经科技」两种格式导出。
  • 铸铁管：名称含「铸铁管 / 机制离心排水铸铁管 / 离心浇筑灰口铁直管 / 柔性接口机制排水铸铁管」等关键词或相近材质，套031001001 铸铁管；结果表「安装部位/接口形式」列可切换室内/室外与青铅/膨胀水泥/石棉水泥/胶圈/水泥接口，定额与主材价实时重算；定额单位为 10m，导出广联达时已按定额单位自动换算。
  • 镀锌钢管：名称含「镀锌钢管 / 内外壁热浸镀锌焊接普通钢管」等关键词或相近材质，套031001002 镀锌钢管；「安装部位/接口形式」列可选室内/室外与螺纹连接 / 螺纹连接（燃气），名称含燃气、煤气、天然气、液化气时自动预选燃气；定额单位为 10m，导出广联达时已按定额单位自动换算。
  • 清单及定额：参照天津市2025清单计价规范（配套2020预算基价第八册 给排水、采暖、燃气工程）编制。
  • 价格依据：依据天津市当月造价信息以及合理市场价格标准计入主材价。
  • 无缝钢管 / 焊接钢管：名称含「无缝钢管 / 内外壁热浸镀锌无缝钢管 / 焊接钢管 / 钢管」等关键词，分别套031001003 无缝钢管、031001004 焊接钢管；室内焊接8-195~8-205、室内沟槽（卡箍）8-206~8-212、室外焊接8-23~8-35，按公称直径就近套档。
  • 铜管：套031001005 铜管；按名称连接方式套卡压8-309~8-317、氧乙炔焊8-318~8-326、钎焊8-327~8-335（公称外径18~108）。
  • 不锈钢管：套031001006 不锈钢管；室内薄壁不锈钢管按卡压8-261~、卡套8-270~、承插氩弧焊8-279~、螺纹8-288~、对接电弧焊8-297~8-308（DN15~200）；名称含燃气时套室内燃气不锈钢管承插氩弧焊8-1141~、卡套8-1148~、卡压8-1154~8-1159（DN15~100）。
  • 复合管：套031001007 复合管；室外钢骨架塑料复合管电熔8-81~8-89、室内钢骨架塑料复合管电熔8-250~8-260、室内铝塑复合管卡压8-227~、卡套8-233~、热熔8-239~8-249（De20~160）。
  • 塑料管：套031001008 塑料管；室外塑料给水热熔8-36~、电熔8-48~、粘接8-60~8-71；室内塑料给水热熔8-410~、电熔8-421~、粘接8-432~8-442；室内塑料排水粘接8-377~8-382、热熔8-383~8-388；室内塑料雨水粘接8-405~8-409。
  • 连接方式：名称含「卡压 / 卡套 / 氩弧焊 / 电弧焊 / 氧乙炔焊 / 钎焊 / 热熔 / 电熔 / 粘接 / 螺纹 / 沟槽（卡箍）/ 焊接」时自动匹配对应子目，未注明时按该材质常用方式预选，结果表「安装部位/接口形式」列可手动切换并实时重算。
  • 附加定额：每条管道自动附加管道消毒冲洗（8-490~8-495，DN50~500，定额单位100m，排水/燃气管一般不计取，可在导出前删除该行）；名称含「卡箍 / 沟槽连接」时自动附加室内管道钢管沟槽连接管件（8-220~8-226，DN65~250，定额单位10个，数量按6m定尺估算，实际按图纸管件数量调整）。
